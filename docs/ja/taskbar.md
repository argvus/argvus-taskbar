---
title: タスクバー
description: ARGVUS Waybar タスクバーを使用してください。
---
タスクバーは、デスクトップ全体にわたる持続的なWaybarの画面です。`argvus-taskbar`はそのARGVUSの設定とアクションを所有し、`argvus-waybar`はそれをレンダリングする修正版Waybarバイナリを提供します。`argvus-session`はサービスのライフサイクルを管理します。

タスクバーはワークスペース、フォーカスされているウィンドウの状態、時計とカレンダーのアクセス、ネットワーク、Bluetooth、オーディオ/メディア、通知、ストレージ、録画、常時オン、電源/セッションの操作を通信します。インストールされているプロバイダーやハードウェアによって、正確なステータスモジュールは影響を受ける可能性があります。

最も左のアイコンは`argvus launcher`を開きます。デフォルトでは無効になっています。有効にすると、アクティブなテーマに従います: テーマビルドではテーマのハイライト色（`taskbar/menu.svg`、このパッケージの`taskbar-menu`テンプレートから）で表示されます。一方、組み込みのARGVUS Dark/ARGVUS Lightテーマでは`menu-default-dark.svg`/`menu-default-light.svg`（いずれも`argvus-branding`によって提供）を使用します。**コントロールセンター → 外観 → タスクバー → アイコン → ランチャー**を使用して有効化/無効化するか、カスタムアイコン画像を選択するとテーマアイコンが上書きされます。

タスクバーはコントロールパネルではありません。バーは永続的なデスクトップの状態とステータスを通知し、コントロールパネルは展開可能なクイックアクションのサーフェスです。カレンダーやリムーバブルデバイスのポップアップは補助的なアプリケーション/サーフェスであり、別のタスクバーではありません。

**メモリ** または **CPU** をクリックすると、テーマ付き ARGVUS モニターパネル内に `btop` が開き、`ARGVUS` ヘッダーと `Esc Close` フッターが表示されます。画面下部の Kitty タブには、ローカライズされた `Press q to close` ヒントが表示されます。`q` または `Esc` を押すと閉じます。CPU 温度モジュールは、チップごとにグループ化されたライブの `argvus sensors` 概要を開きます。サポートされている GPU と `btop` が利用可能な場合に GPU 温度モジュールが表示されます。これには、最大の GPU 温度または `N/A` が表示され、クリックすると同じテーマフレーム内で GPU 専用の btop パネルが開きます。btop は最大 6 つの GPU ボックスをサポートします。NVIDIA のメトリクスにはその GPU サポートと NVML が必要で、AMD のメトリクスには ROCm SMI、Intel のメトリクスには読み取り可能な sysfs インターフェースが必要です。GPU 温度は、そのデバイスに関連する読み取り値がシステムによって提供される場合にのみ表示されます。Intel 温度は btop 1.4.7 では利用できません。サポートまたはプロバイダーの不足により btop が GPU ボックスを描画できない場合は 欠落している場合、ARGVUSパネルはメトリクスが利用できないことを報告します。ARGVUSはシステム権限を変更しません。

## 位置と間隔

デフォルトの位置はドックモードでの上端です。コントロールセンターは、**外観 → タスクバー → 位置** および **スペース** でタスクバーの位置とタスクバー/シェルのマージンを、**外観 → タスクバー → アイコン** でユーティリティグループを公開します。レイアウト状態は、独立した上、左、右、下のマージンを保存します。スティッキーモードは下マージンを `2` に設定し、バーを端に近づけたままにします。スペースモードはデフォルトで `18` ユニットのシェルマージンを使用します。

タスクバーマージン、ウィンドウ外側のギャップ、およびパネルのジオメトリは関連していますが別物です。1つを変更しても他のすべての値が書き換えられるわけではありません。バーがウィンドウから視覚的に離れて表示される場合は、モード、タスクバーマージン、ウィンドウ間隔を一緒に確認してください。[Windows and layout](/docs/argvus-hyprland/windows-and-layout/)を参照してください。

タスクバーの位置制御は現在、**上**または**下**を選択できます。四つの独立したマージンは、バーが画面の各端からどれだけ離れているかを制御します。ユーティリティグループは**自動**または**常に展開**の動作を使用できます。モジュールの利用可能性は、インストールされているプロバイダーおよびハードウェアに依存するため、Bluetooth、輝度、またはストレージのインジケーターが欠けている場合でも、バーの間隔を変更しても生成されません。

**高さ**はバーの高さを24、28（デフォルト）、32、または36ピクセルに設定します。**ボーダー**はタスクバーのボーダーをオンまたはオフにし、その厚さを1、2、または3ピクセルに設定します。この厚さはタスクバーウィンドウ、`right-0`、`right-1`、`focus`、`right-2`グループ、およびMPRISプレイヤーボーダーに適用されます。プレイヤーを含むインタラクティブモジュールにカーソルを合わせると、不透明度が穏やかに下がります。ボーダーがオフの場合、それらのボーダーは`0px`として記録されます。両方とも**コントロールセンター → 外観 → タスクバー**で、**[ 適用 ]**を選択するまでドラフトとして扱われます。**コントロールセンター → 外観 → タスクバー → アイコン → オプションモジュール** は、オプションのステータスおよびアクションモジュールの表示を制御します。ワークスペース、フォーカスのあるウィンドウのタイトル、設定、電源は引き続き利用可能です。**ワークスペースの表示**は、ワークスペースラベル（デフォルト）またはアプリケーションアイコンを選択します。MPRISプレイヤーはツールチップにトラック詳細を表示します。プレイヤーはもはや連続的なカラーパルスを使用しません。

## 透明度とぼかし

**コントロールセンター → 外観 → タスクバー** を使用してユーティリティアイコン、透明度、ぼかしを設定します。透明度とぼかしにはそれぞれ有効スイッチと `0–100%` 値があります。`+` と `-` を使って値を5%単位で変更します。変更は **[ 適用 ]** を選択するまで下書き状態です。新しいテーマでは、両方の効果が `50%` で有効になった状態がデフォルトです。
`↑/↓` を使用して、有効行と値行の間を移動します。`Tab` を押して **操作** を選択し、**[ 適用 ]** を有効にします。

## 設定と上書き

タスクバーの構成は`argvus-taskbar`によって所有され、`argvus-waybar`によってレンダリングされ、`argvus-session`によって開始されます。`argvus-config`はタスクバーのコンシューマファイルを書き込む唯一のコンポーネントです。これは`~/.config/argvus/data/generated/waybar/`の下でアクティブレイヤーを投影し、テーマレイヤー、タスクバーのマージン、`right-2`ユーティリティグループモード、ボーダー半径およびフォントブロックを、テーマやレイアウトの状態が変更されるたびに再適用します。テーマの切り替えは、パッケージ化されたタスクバーファイルを復元し、その後、コントロールセンターで選択された高さとボーダーを書き戻します。これらはargvus config内の`/taskbar/shape/height`および`/taskbar/shape/border_width`として保存されます。選択されるまでは `argvus config` `null`であり、テーマに従います：高さ28ピクセル、ボーダー1ピクセル（Slate Darkにはボーダーなし）。生成されたコピーが最初に解決されるため、`~/.config/waybar/`下のネイティブWaybarパスは、対応する生成ファイルが存在しない場合にのみ有効です。優先順位、例およびトラブルシューティングについては[Waybar and taskbar overrides](/docs/argvus-waybar/)を参照してください。

## ウィンドウとパネル

タスクバーは、コントロールパネルやオプションのテレメトリウィジェットと並ぶシェルのサーフェスです。Hyprland はアクティブなレイアウト状態に従ってウィンドウを配置しますが、これらのサーフェスには独自のアンカーとマージンがあります。`SUPER + SHIFT + Space` は、フォーカスされているウィンドウをタイルレイアウトとフローティングレイアウトの間で切り替えます。

## 時計とフォーカス

タイムモジュール（`clock#time`）は、ARGVUSクロックのポップアップを開いたり隠したりし、そのルートクリック座標を渡して、クリックされたタスクバーやモニターと整列させます。フォーカスインジケーターは、ネットワーク/パフォーマンスグループ（ `focus` `right-1`）と日付/時刻（`right-0`）の間に、独自のfocusグループを持っています。これはGTKを読み込まずに`argvus focus status --waybar --follow`を実行します：アイドル時にはタイマーアイコンを表示し、フォーカスまたは休憩フェーズ中には残りの`MM:SS`を追加します；その色はフェーズと一時停止状態を識別します。クリックすると、そのクリック位置でフォーカスポップアップを開いたり隠したりします。両方のポップアップは、**Esc**キーまたはポップアップ外のクリックでも閉じることができます。

## 再読み込み

メインサービスは`argvus-taskbar.service`です。ドキュメント化された設定変更で手動の再読み込みが必要な場合は、セッションコントローラーを使用してください：

```sh
argvus sessionctl restart waybar
```
カレンダーとリムーバブルストレージのポップアップは、ARGVUS Waybar ビルドによって提供される不変のルート座標契約を使用してモニターを識別します。カレンダーは実際の水平タスクバーの面に従います：上部バーの下4ピクセルまたは下部バーの上4ピクセルに開きます。クリックした日付モジュール内の位置に関係なく、日付モジュールがカレンダーを開きます。永続的な変更を行うために生成されたランタイム設定を編集しないでください。Control Center または文書化された [Waybar override](/docs/argvus-waybar/) パスを使用してください。

ユーティリティはホバーモードではエクスパンダーに折りたたまれ、ポインターが入ると有効なコントロールを表示します。システムトレイの表示設定はバックグラウンドアプリケーションのアイコンを制御します。トレイが空の場合、アイコンは表示されません。ワークスペースアイコンの表示は、ワークスペースラベルとともに開いているウィンドウのアプリケーションアイコンを表示します。

## プロジェクトワークスペース

開いているプロジェクトは、`Project: name` とラベル付けされた通常のワークスペースボタンとして表示されます。クリックするとそのワークスペースにフォーカスが移ります。ホバーすると、プロジェクトのフルパスと `SUPER + ALT + N` ショートカットが表示されます。バーのモニター上で開かれているワークスペースのみが表示されます；ピッカー（`SUPER + O`）は引き続きフルプロジェクトカタログを保持します。特別なワークスペースは既存の可視性ポリシーを維持します。

`hyprland/workspaces` モジュールは `workspace-metadata: "argvus/project-workspaces.json"` を `$XDG_RUNTIME_DIR` に対して読み込みます。`argvus projects` はプロジェクトが開かれるたびにこの派生ファイルを再生成します。パッチされた `argvus-waybar` は Hyprland 0.57 のテキストベースのワークスペースアドレスをサポートし、ワークスペースのIDを変更せずにラベルにメタデータを使用します。3つのパッケージすべてを更新し、サービスを再起動する前にタスクバー構成を再プロジェクトしてください。

**更新ステータス**モジュールは、ユーティリティとネットワーク/パフォーマンスの間に独自のグループを持ち、利用可能なパッケージ更新の数を表示します。起動時および`checkupdates`（`pacman-contrib`から）を使用して毎時公式リポジトリをチェックしますが、パッケージはアップグレードしません。**AURをチェック**はデフォルトでオフです。有効にすると、`paru`または`yay`でチェックします。ツールチップはソースを分け、失敗を報告します。`?`は合計が不完全であることを意味します。モジュールをクリックすると、パッケージで公式の更新を開きます。両方のオプションは**アイコン → オプションモジュール**で設定でき、タスクバードラフトを適用します。モジュールはデフォルトで有効です。
