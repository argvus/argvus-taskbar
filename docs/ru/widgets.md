---
title: Виджеты
description: Настройте необязательные виджеты системной телеметрии.
---
`argvus widget-telemetry` предоставляет дополнительную вспомогательную панель Waybar для системной информации. В настоящий момент её блоки: **Система**, **CPU/GPU**, **Память**, **Хранилище**, **Процессы**, **Сеть** и **Ярлыки**. Блок Ярлыки хранится с ключом `keys` в файле состояния.

Используйте **Центр управления → Внешний вид → Телеметрия виджетов**, чтобы включить панель и включать или выключать отдельные блоки. Отключение блока скрывает этот модуль телеметрии из профиля Waybar; это не удаляет пакет и не останавливает остальную сессию. Главный переключатель управляет всей панелью телеметрии в целом.

Выбор блока является каноническим в `config.json`, в `control_panel.widget_telemetry_blocks`, а главный переключатель находится в `control_panel.widget_telemetry_enabled`. `argvus-config` проецирует этот выбор в профиль Waybar `data/waybar/argvus-widget-telemetry.jsonc`, раскомментируя или комментируя строки внутри его ограниченных блоков `ARGVUS_TELEMETRY_<BLOCK>_BEGIN`/`_END`, оставляя остальную часть файла нетронутой. Файл устаревшего формата `~/.local/state/argvus/widget-telemetry-blocks` все еще читается как аварийный вариант миграции на старых установках, но он никогда не записывается. Обратите внимание, что весь профиль заменяется на упакованный по умолчанию при изменении внешнего вида, поэтому маркеры блоков сохраняют выбор; текст за их пределами при смене темы не сохраняется.

Контроллер поддерживает:

```sh
argvus widget-telemetry-toggle status
argvus widget-telemetry-toggle on
argvus widget-telemetry-toggle off
argvus widget-telemetry-toggle blocks status
argvus widget-telemetry-toggle blocks set memory disabled
argvus widget-telemetry-toggle blocks apply
```
Контроллер также принимает `blocks set <block> <enabled|disabled>` для `system`, `cpu_gpu`, `memory`, `storage`, `processes`, `network` и `keys`. Предпочтения сохраняются; когда у блока нет явного предпочтения, он следует включённому по умолчанию. `blocks set` переписывает канонический массив в одном атомарном патче, затем повторно проецирует профиль Waybar и согласует жизненный цикл сервиса. `apply-state` — это путь Центра управления: он предполагает, что вызывающая сторона уже сохранила выбор, и лишь проецирует его, поэтому никогда не вызывайте его с несохранённым состоянием.

Сервис — `argvus-widget-telemetry.service` и управляется `argvus-session`. На текущей странице нет отдельной кнопки сброса для каждого блока: снова включите блок или используйте поддерживаемое провайдером управление состоянием, вместо того чтобы редактировать сгенерированный вывод Waybar.

## Прозрачность и размытие

Используйте **Центр управления → Внешний вид → Телеметрия виджетов** для настройки главного переключателя, сессий телеметрии, прозрачности и размытия. Оба эффекта имеют независимые переключатели включения и значения `0–100%`. Используйте `+` и `-` с шагом 5% и выберите **[ Применить ]**; значения применяются только после подтверждения и сохраняются для активной темы.
Используйте `↑/↓` для перехода между строками включения и значений. Нажмите `Tab` для **Действий**, затем активируйте **[ Применить ]**.

Модуль температуры GPU отображается, когда DRM/sysfs обнаруживает поддерживаемый GPU NVIDIA, AMD или Intel и установлен `btop`. Его значение — это наивысшая допустимая температура, которая может быть приписана одному из обнаруженных GPU; когда датчик не доступен, отображается `N/A`. Щелчок по нему открывает панели btop только для GPU в Kitty через `argvus tui-terminal` с использованием профиля `taskbar-monitor`. Нажмите `q` или `Esc`, чтобы закрыть; локализованная нижняя вкладка показывает `Press q to close`. btop 1.4.7 поддерживает до шести блоков GPU. Метрики NVIDIA требуют поддержки GPU в btop и NVML; AMD требует поддержки GPU в btop и ROCm SMI; Intel требует доступных интерфейсов sysfs. Температуры NVIDIA nouveau, AMD и Intel отображаются только при наличии связанного датчика hwmon. ARGVUS не изменяет разрешения и не добавляет привилегированные вспомогательные программы. Пакет панели задач зависит от btop; поставщики от производителя остаются опциональными.


Необязательный значок AI-агентов в группе/right-2 открывает меню argvus-ai. Он проверяется каждые пять секунд и скрывается, когда помощник отсутствует или агенты недоступны (argvus-ai status --check). Claude предлагается для установки, когда присутствует mise. Его выбор открывает терминал ARGVUS, устанавливает его в текущем профиле пользователя, если отсутствует, а затем запускает его с каталогом бинарных файлов в PATH процесса. Хук установки пакета не используется. Перезагрузите панель, чтобы загрузить обновленную конфигурацию системы; пользовательские копии не перезаписываются.

AI-запуск использует nf-md-robot (U+F06A9) с шрифтом Symbols Nerd Font Mono. Проектор внешнего вида сохраняет его в группе/right-2 вместе с микрофоном и элементами управления звуком.

## Селектор оконного режима

Иконка окна в `group/right-2`, после расширения утилиты, открывает всплывающее окно GTK с **Tile Windows (По умолчанию)** и **Floating Windows**. Текущие предпочтения отмечены. Выберите вариант, чтобы применить его немедленно; Escape или клик вне окна закрывает всплывающее меню. Иконка отображает текущий режим, с индикатором ожидания/ошибки, если приложение не завершило работу. Всплывающее окно следует позиции панели задач и текущей теме.

Настройка общая с **Control Center → Desktop & Input → Hyprland → Windows → Mode**. Floating влияет на все окна приложений на всех мониторах и рабочих пространствах. Возврат к Tile сохраняет окна, которые изначально были плавающими. Выбор сохраняется между входами в систему.

Помощник — `argvus window-mode-menu`; `argvus window-mode-menu --status` выводит Waybar JSON. Он поставляется в составе основного пакета `argvus`. Существующие пользовательские копии панели задач сохраняются: добавьте определение модуля `custom/window-mode` и запись группы из шаблона пакета, чтобы подключиться, или используйте Панель управления. Проектор внешнего вида сохраняет модуль, если его определение присутствует, даже если другие системные значки отключены.

## Кнопки окна и панель приложений

Плавающий режим добавляет заголовок ARGVUS с **Свернуть**, **Развернуть / Восстановить** и **Закрыть** к обычным окнам приложений. Двойной щелчок по заголовку переключает развертывание на весь экран. Дополнительное оформление скрыто в Tile и полноэкранном режиме. Приложения, которые рисуют свои собственные элементы управления, могут отображать обе панели; единообразные элементы управления ARGVUS нарочиты.

Второй Waybar появляется на каждом мониторе, на краю, противоположном главной панели задач. Он отображает только окна текущего рабочего пространства этого монитора, включая свернутые окна. Скрытые вкладки групп не создают дополнительных записей. Свернутые записи сохраняют своё изначальное назначение по монитору/рабочему пространству. Щелкните по неактивному окну для его активации, по активному окну для сворачивания или по свернутому окну для восстановления; в его контекстном меню доступны восстановление, сворачивание, развернуть/восстановить и закрыть. Значки неизвестных приложений заменяются символом окна. Активация или восстановление записи сохраняет положение указателя. Вторичная панель использует текущий основной CSS (цвета, шрифты, границы и скругления), с учётом её высоты и зеркальных отступов на противоположном краю.

`SUPER + Alt + Up` размещает основную панель вверху, а панель окна внизу. `SUPER + Alt + Down` делает наоборот. Повторение направления оставляет позиции без изменений. У Tile есть только основная панель. Возврат к Tile восстанавливает все свернутые окна перед удалением панели окна и затем сохраняет исходную политику размещения по сетке/с плавающим окном.

Минимизация использует зарезервированное рабочее пространство `special:argvus-minimized`. Не используйте это рабочее пространство вручную. Процесс `argvus windows service` записывает идентичность, исходное рабочее пространство/монитор, геометрию, полноэкранный режим/максимизацию и состояние закрепления в реестре времени выполнения, специфичном для экземпляра композитора, под `$XDG_RUNTIME_DIR/argvus`. Записи сохраняются при перезапуске службы или перезагрузке конфигурации, но не переходят между сеансами композитора. Закрытие окна удаляет его запись. Если монитор исчезает, восстановление использует доступный выход. Отсутствие или сбой панели восстановления предотвращает новые минимизации; при сбое восстановления запись сохраняется, а панель восстановления сохраняется.

Сеанс владеет `argvus-windows.service` и `argvus-window-bar.service`. Последнее удерживает своего дочернего Waybar в спящем режиме в Tile. Плагин hyprbars включен `argvus-hyprland`, собран для ABI Hyprland 0.57.0 на x86_64; он не компилируется в домашнем каталоге пользователя. Пересоберите плагин при обновлении ABI композитора. Команды: `argvus windows list --json`, `watch --json`, `position top|bottom`, `restore-all` и `minimize|restore|activate|maximize|close ADDRESS`. Адреса окон берутся из списка. `position top --persist` сохраняет/применяет предпочтение без перезапуска основной панели. Детали конфигурации и ошибок во время выполнения записываются в журнал; видимые сбои действий также показывают переведённое уведомление.

В **Spaced + Floating** окна учитывают внешние зазоры и зоны, зарезервированные обеими панелями. Границы включают рамку и заголовок, который находится внутри той же рамки окна. Максимизация через ARGVUS контролы заполняет эту область с учётом полей; восстановление возвращает предыдущую геометрию, включая после перезапуска службы. Режим полноэкранного просмотра по-прежнему использует весь вывод. Плавающие окна могут перекрывать друг друга; внутренние зазоры для тайлинга их не разделяют.
