title: 작업 표시줄

---
작업 표시줄은 데스크탑 전체에서 지속되는 Waybar 표면입니다. `argvus-taskbar`는 그 ARGVUS 구성 및 동작을 소유하며, `argvus-waybar`는 이를 렌더링하는 패치된 Waybar 바이너리를 제공합니다. `argvus-session`는 서비스 생명주기를 소유합니다.

작업 표시줄은 작업 공간, 포커스된 창 상태, 시계 및 달력 접근, 네트워크, 블루투스, 오디오/미디어, 알림, 저장소, 녹화, 깨어 있기 및 전원/세션 동작을 통신합니다. 정확한 상태 모듈은 설치된 제공자와 하드웨어에 의해 영향을 받을 수 있습니다.

가장 왼쪽 아이콘은 `argvus launcher`를 엽니다. 기본적으로 비활성화되어 있습니다. 활성화되면, 활성 테마를 따릅니다: 테마 빌드는 테마의 강조 색상(`taskbar/menu.svg`, 이 패키지의 `taskbar-menu` 템플릿에서 가져옴)으로 아이콘을 렌더링하며, 내장된 ARGVUS Dark/ARGVUS Light 테마는 `menu-default-dark.svg`/`menu-default-light.svg`(모두 `argvus-branding`에서 제공)을 사용합니다. 아이콘을 활성화/비활성화하거나 테마 아이콘을 덮어쓸 맞춤 아이콘 이미지를 선택하려면 **제어 센터 → 외형 → 작업 표시줄 → 아이콘 → 런처**를 사용하세요.

작업 표시줄은 제어판이 아닙니다. 이 표시줄은 지속적인 데스크톱 상태와 상태를 전달하며, 제어판은 확장 가능한 빠른 작업 영역입니다. 달력 및 이동식 장치 팝업은 별도의 작업 표시줄이 아닌 보조 애플리케이션/화면입니다.

**Memory** 또는 **CPU**를 클릭하면 테마 ARGVUS 모니터 패널 안에 `btop`가 열리며, `ARGVUS` 헤더와 `Esc Close` 푸터가 표시됩니다. 하단 Kitty 탭에는 현지화된 `Press q to close` 힌트가 나타납니다. `q` 또는 `Esc`를 눌러 닫을 수 있습니다. CPU 온도 모듈은 칩별로 그룹화된 실시간 `argvus sensors` 개요를 엽니다. 지원되는 GPU와 `btop`가 있을 때 GPU 온도 모듈이 표시되며, 최고 GPU 온도 또는 `N/A`를 보여주고, 클릭하면 같은 테마 프레임 안에서 GPU 전용 btop 패널이 열립니다. btop은 최대 여섯 개의 GPU 박스를 지원합니다. NVIDIA 지표는 GPU 지원과 NVML이 필요하며, AMD 지표는 ROCm SMI가 필요하고, Intel 지표는 읽을 수 있는 sysfs 인터페이스가 필요합니다. GPU 온도는 시스템이 해당 장치와 연결된 값을 노출할 때만 표시되며, Intel 온도는 btop 1.4.7에서 제공되지 않습니다. btop이 지원이나 제공자가 없기 때문에 GPU 박스를 렌더링할 수 없을 때 누락된 경우, ARGVUS 패널은 메트릭을 사용할 수 없다고 보고합니다. ARGVUS는 시스템 권한을 변경하지 않습니다.

## 위치 및 간격

기본 위치는 도크 모드에서 상단 가장자리입니다. 제어 센터는 **Appearance → Taskbar → Position** 및 **Spaces**에서 작업 표시줄 위치 및 작업 표시줄/쉘 여백을 노출하며, **Appearance → Taskbar → Icons**에서 유틸리티 그룹을 노출합니다. 레이아웃 상태는 독립적인 상, 좌, 우, 하 여백을 저장합니다. 스티키 모드는 하단 여백을 `2`로 기본 설정하고 바를 가장자리 근처에 유지합니다; Spaced 모드는 기본 `18` 단위 쉘 여백을 사용합니다.

작업 표시줄 여백, 창 외부 간격 및 패널 지오메트리는 관련이 있지만 서로 다릅니다. 하나를 변경한다고 해서 다른 모든 값이 다시 작성되지는 않습니다. 바가 시각적으로 창에서 분리되어 보이는 경우, 모드, 작업 표시줄 여백 및 창 간격을 함께 검토하십시오; [Windows and layout](/docs/argvus-hyprland/windows-and-layout/)를 참조하세요.

작업 표시줄 위치 제어는 현재 **위쪽** 또는 **아래쪽**을 선택할 수 있습니다. 네 개의 독립 마진은 작업 표시줄이 각 화면 가장자리로부터 얼마나 떨어져 있는지를 제어합니다. 유틸리티 그룹은 **자동** 또는 **항상 확장됨** 동작을 사용할 수 있습니다. 모듈의 사용 가능 여부는 여전히 설치된 제공자 및 하드웨어에 따라 달라지므로, 블루투스, 밝기 또는 저장 장치 표시기가 없다고 해서 바 간격을 변경한다고 생성되지 않습니다.

**높이**는 작업 표시줄 높이를 24, 28(기본값), 32 또는 36픽셀로 설정합니다. **테두리**는 작업 표시줄 테두리를 켜거나 끄고, 두께를 1, 2 또는 3픽셀로 설정합니다. 두께는 작업 표시줄 창, `right-0`, `right-1`, `focus`, `right-2` 그룹 및 MPRIS 플레이어 테두리에 적용됩니다. 플레이어를 포함한 상호작용 모듈에 마우스를 올리면 불투명도가 살짝 낮아집니다. 테두리를 끄면 해당 테두리는 `0px`로 표시됩니다. 두 가지 모두 **제어 센터 → 모양 → 작업 표시줄**에서 **[ 적용 ]**을 선택할 때까지 초안 상태로 남아 있습니다.**제어 센터 → 모양 → 작업 표시줄 → 아이콘 → 선택적 모듈**은 선택적 상태 및 작업 모듈의 표시 여부를 제어합니다. 작업 공간, 현재 창 제목, 설정 및 전원은 계속 사용할 수 있습니다. **작업 공간 표시**에서는 작업 공간 라벨(기본값) 또는 애플리케이션 아이콘을 선택할 수 있습니다. MPRIS 플레이어는 툴팁에 트랙 세부 정보를 표시하며, 플레이어는 더 이상 연속 색상 깜박임을 사용하지 않습니다.

## 투명도 및 블러

**제어 센터 → 모양 → 작업 표시줄**을 사용하여 유틸리티 아이콘, 투명도 및 블러를 구성할 수 있습니다. 투명도와 블러에는 각각 활성화 스위치와 `0–100%` 값이 있습니다. `+` 및 `-`로 값을 5% 단위로 변경할 수 있으며, 변경 사항은 **[ 적용 ]**을 선택할 때까지 임시 저장됩니다. 새 테마는 두 효과가 모두 `50%`에서 활성화된 상태로 기본 설정됩니다.  
`↑/↓`를 사용하여 활성화 행과 값 행 사이를 이동합니다. **작업**을 위해 `Tab`를 누른 후 **[ 적용 ]**을 활성화하세요.

## 구성 및 재정의

작업 표시줄 구성은 `argvus-taskbar`가 소유하고, `argvus-waybar`가 렌더링하며, `argvus-session`가 시작합니다. `argvus-config`는 작업 표시줄 소비자 파일을 쓰는 유일한 구성 요소입니다: 이는 `~/.config/argvus/data/generated/waybar/` 아래에서 활성 레이어를 투사하고, 테마 레이어, 작업 표시줄 여백, `right-2` 유틸리티-그룹 모드, 테두리 반경 및 글꼴 블록을 테마나 레이아웃 상태가 변경될 때마다 다시 적용합니다. 테마 전환 또한 패키지된 작업 표시줄 파일을 복원한 후, 제어 센터에서 선택한 높이와 테두리를 다시 작성하며, 이는 argvus config에서 `/taskbar/shape/height`와 `/taskbar/shape/border_width`로 저장됩니다. 하나가 선택될 때까지는  `argvus config` `null`이며 테마를 따릅니다: 높이 28px, 테두리 1px (Slate Dark에는 없음). 생성된 사본이 먼저 해결되기 때문에, `~/.config/waybar/` 아래의 네이티브 Waybar 경로는 해당 생성 파일이 없을 때만 적용됩니다. 우선순위, 예제 및 문제 해결은 [Waybar and taskbar overrides](/docs/argvus-waybar/)를 참조하십시오.

## 윈도우 및 패널

작업 표시줄은 제어판 및 선택적 텔레메트리 위젯과 함께 있는 하나의 셸 표면입니다. Hyprland는 활성 레이아웃 상태에 따라 창을 배치하는 반면, 이러한 표면들은 자체적인 앵커와 여백을 가지고 있습니다. `SUPER + SHIFT + Space`는 포커스된 창을 타일 레이아웃과 플로팅 레이아웃 사이에서 전환합니다.

## 시계와 포커스

시간 모듈(`clock#time`)은 ARGVUS 시계 팝업을 열거나 숨기고, 클릭된 작업 표시줄 및 모니터에 맞추기 위해 루트 클릭 좌표를 전달합니다. 포커스 표시기는 네트워크/성능 그룹( `focus` `right-1`)과 날짜/시간(`right-0`) 사이에 자체 focus 그룹을 가지고 있습니다. 이는 GTK를 로드하지 않고 `argvus focus status --waybar --follow`를 실행하며, 유휴 상태에서는 타이머 아이콘을 표시하고 포커스 또는 휴식 단계 동안에는 남은 `MM:SS`를 추가하며, 색상은 단계와 일시 중지 상태를 나타냅니다. 클릭하면 해당 위치에서 포커스 팝업을 열거나 숨깁니다. 두 팝업 모두 **Esc** 키를 누르거나 외부를 클릭하면 닫힙니다.

## 다시 로드

메인 서비스는 `argvus-taskbar.service`입니다. 문서화된 구성 변경으로 인해 수동으로 다시 로드해야 하는 경우 세션 컨트롤러를 사용하세요:

```sh
argvus sessionctl restart waybar
```
캘린더 및 제거 가능한 저장소 팝업은 ARGVUS Waybar 빌드에서 제공하는 불변 루트 좌표 계약을 사용하여 모니터를 식별합니다. 캘린더는 실제 수평 작업 표시줄 표면을 따릅니다: 상단 바 아래 4픽셀 또는 하단 바 위 4픽셀에 열리며, 날짜 모듈 내 어디를 클릭했는지와 상관없이 날짜 모듈이 캘린더를 엽니다. 지속적인 변경을 위해 생성된 런타임 구성을 편집하지 마십시오; 제어 센터 또는 문서화된 [Waybar override](/docs/argvus-waybar/) 경로를 사용하십시오.

유틸리티는 호버 모드에서 확장기로 축소되며 포인터가 진입하면 활성화된 컨트롤을 표시합니다. 시스템 트레이 가시성은 백그라운드 응용 프로그램 아이콘을 제어합니다; 비어 있는 트레이에는 표시 가능한 아이콘이 없습니다. 워크스페이스 아이콘 표시에는 열린 창의 응용 프로그램 아이콘과 워크스페이스 레이블이 함께 표시됩니다.

## 프로젝트 워크스페이스

열린 프로젝트는 일반 작업 공간 버튼으로 표시되며, `Project: name`라고 라벨이 붙습니다; 클릭하면 해당 작업 공간으로 포커스가 이동합니다. 마우스를 올리면 전체 프로젝트 경로와 `SUPER + ALT + N` 바로가기가 표시됩니다. 막대의 모니터에서 열린 작업 공간만 표시되며; 선택기(`SUPER + O`)는 전체 프로젝트 카탈로그를 유지합니다. 특별한 작업 공간은 기존의 가시성 정책을 유지합니다.

`hyprland/workspaces` 모듈은 `workspace-metadata: "argvus/project-workspaces.json"`를 `$XDG_RUNTIME_DIR` 기준으로 읽습니다. `argvus projects`는 프로젝트가 열릴 때마다 이 파생 파일을 재생성합니다. 패치된 `argvus-waybar`는 Hyprland 0.57 텍스트 작업 공간 주소를 지원하고, 작업 공간 아이덴티티를 변경하지 않고 라벨을 위해 메타데이터를 사용합니다. 세 가지 패키지를 모두 업데이트하고 서비스를 재시작하기 전에 작업 표시줄 구성을 다시 투영하세요.

**업데이트 상태(Update Status)** 모듈은 유틸리티(Utilities)와 네트워크/성능(network/performance) 사이에 자체 그룹이 있으며, 사용 가능한 패키지 업데이트 수를 표시합니다. 이 모듈은 시작 시와 매시간 `checkupdates`(`pacman-contrib`에서 가져옴)을 사용하여 공식 저장소를 확인하며 패키지를 업그레이드하지는 않습니다. **AUR 확인(Check AUR)**은 기본적으로 꺼져 있으며, 활성화하면 `paru` 또는 `yay`과 확인합니다. 툴팁은 소스를 구분하고 실패를 보고하며, `?`는 총합이 불완전함을 의미합니다. 모듈을 클릭하면 패키지에서 공식 업데이트가 열립니다. 두 옵션은 **아이콘 → 선택적 모듈(Icons → Optional modules)**에서 구성하고 작업 표시줄 초안을 적용합니다. 모듈은 기본적으로 활성화되어 있습니다.
